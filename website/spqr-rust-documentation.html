Documentation

SPQR-Rust computes connected components, biconnected blocks and SPQR trees.

IDs are 32-bit by default. The optional wide API uses 64-bit IDs. See Identifier size.

For C++ code using OGDF, a C++ graph library, choose spqr::ogdf_compat to simplify the transition to SPQR-Rust. Choose spqr when reducing storage and data-access costs is the priority. Both use the same Rust SPQR builder. Compare the two interfaces, then choose direct construction or compression followed by reconstruction.
