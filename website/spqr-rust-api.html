Main modules

ModuleContents
spqr_rustGraph, node/edge IDs, SPQR tree builders and tree methods.
connectedList the connected parts, count them and identify the part containing each vertex.
biconnectedFind biconnected blocks and the vertices where they meet, represented as a block-cut tree.
verifyCheck SPQR trees and report errors. Optionally require that no S node is adjacent to another S node and no P node to another P node.
spqr_formatText writers, parser records and validation.
sp_compressInput and results for replacing paths and parallel edges, saving those reductions and reconstructing the tree.
wideGraph and SPQR tree types using 64-bit IDs (8 bytes per ID).
ffiC functions for graphs and decompositions, reading result arrays and allocating or releasing Rust data.

Compression modules

ModuleContents
sp_compress::integrationCompress the graph, build the remaining core's SPQR tree, and return statistics and vertex-ID mappings.
sp_compress::reductionCompression functions, including versions that read your existing input arrays without copying them.
sp_compress::reconstructRecover the full SPQR tree from saved reductions and the core tree. Optionally report elapsed times for each step.
sp_compress::typesRecords for saved reductions and the remaining graph, functions for reading their contents, and statistics.
sp_compress::wideCompression using 64-bit IDs, including a function that renumbers widely spaced input IDs.
sp_compress::reconstruct_wide64-bit reconstruction and timings.
sp_compress::ffiCompression handles, snapshots, arrays, timings and reconstruction exports.
sp_compress::isoDescribe trees as comparable byte sequences and compare those sequences.
sp_compress::adjStore the edges incident to each vertex during compression.
sp_compress::arenaAllocate records for removed paths and parallel connections, and combine those records.
sp_compress::pmapIndex pairs of vertices during compression.
sp_compress::directModule used when compression reads separate edge-endpoint arrays. Its operations are callable only inside the Rust library.

Rebuild the reference

From the BubbleFinder checkout, with a local SPQR-Rust checkout available:

Terminal
python3 website/tools/build_spqr_reference.py \
  --source /path/to/spqr-rust --output /tmp/spqr-reference

The helper generates the public Rust API, all header pages and a version manifest. Review the output, then replace website/spqr-rust-api/ with the generated directory. Keep the manual aligned with the source revision.
