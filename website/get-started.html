Getting started

Install BubbleFinder, try a small example, then use your own GFA or GBZ graph.

Installation

In a terminal with Conda available:

Terminal
conda create -n bubblefinder -c conda-forge -c bioconda bubblefinder
conda activate bubblefinder
BubbleFinder --help

Download the latest Linux release, then open a terminal in the download directory.

Terminal
chmod +x BubbleFinder
./BubbleFinder --help

Use ./BubbleFinder in the commands below when running a downloaded binary.

On Linux, with Git, CMake, a C++ compiler, Rust/Cargo and OpenSSL installed:

Terminal
git clone --recurse-submodules https://github.com/algbio/BubbleFinder
cd BubbleFinder
cmake -S . -B build
cmake --build build -j 4
./build/BubbleFinder --help

Use ./build/BubbleFinder in the commands below when running from this directory. See the build instructions for dependencies.

Example graph

Download variation.gfa. It contains six short sequence nodes, including two alternative paths with an A or a G.

In the directory containing the file, run:

Terminal
BubbleFinder ultrabubbles -g variation.gfa -o ultrabubbles.txt

This writes the result to ultrabubbles.txt.

Output

Output format example
1
u+ v-

The first line counts the result lines that follow. Each pair identifies a region by its boundary nodes, with + and - indicating their sides. Here, u and v enclose the A/G alternative.

BubbleFinder reports graph regions. Interpreting them as genetic variants also requires the sequences and paths in your graph. See output conventions

Your own graph

Replace the example with your GFA or GBZ file. Use -j to set the number of threads.

Terminal
BubbleFinder ultrabubbles -g pangenome.gbz -o ultrabubbles.txt -j 8

To look for regions with different properties, choose snarls, d-bubbles or superbubbles.

The default ultrabubble method worked on all pangenome graphs we tested. See special cases for the graph conditions.
