Introduction

SPQR-Rust is a Rust library for computing SPQR trees of undirected multigraphs. An SPQR tree describes how a graph splits into parts joined through pairs of vertices. The library also provides C and C++ interfaces.

The implementation follows the algorithm of Hopcroft and Tarjan, with corrections by Gutwenger and Mutzel.

Each tree node contains a small graph called a skeleton. S skeletons are cycles, P skeletons have parallel edges between two vertices, and R skeletons stay connected after removing any two vertices. Real edges come from the input graph. A virtual edge represents the part attached through another skeleton. Virtual edges come in matching pairs, one in each neighbouring skeleton.

Decompositions

The input to build_spqr must be biconnected: removing any single vertex must leave the graph connected. For a more general graph, find its biconnected blocks first.

connected_componentsThe separate connected parts of a graph.

Documentation

The manual covers ordinary graph use, compression and specialised interfaces. The API reference contains the public Rust API and complete C/C++ headers.

For C++ integration, SPQR-Rust offers two interfaces: spqr::ogdf_compat to simplify the transition from OGDF, a C++ graph library, and spqr for code where performance is the priority, using compact edge values and fewer array checks. Both use the same Rust SPQR builder. See which interface to choose and their memory and runtime costs.

Use in BubbleFinder

BubbleFinder uses SPQR-Rust for snarls, superbubbles and ultrabubbles --spqr-weak-superbubbles, through the framework of Sena et al., 2026.

BubbleFinder handles GFA and GBZ graphs and can export their SPQR-tree decompositions.
