Documentation

A short guide to bubble types, ultrabubble options and output conventions. The README has the full command reference.

Ultrabubbles

Choose these for regions with alternative paths but no internal loops or branches ending inside them, as in region (a) of the figure. The definition was introduced by Paten et al., 2017.

The default method worked on all pangenome graphs we tested. We did not observe the special cases below. The default method and --d-bubbles are generally the fastest options.

Method flagHow it finds ultrabubbles
None (default)Orients the graph, using the method of Harviainen et al., 2026.
--spqr-weak-superbubblesUses SPQR trees and the framework of Sena et al., 2026.
--d-bubblesFinds ultrabubbles among d-bubbles using dominator trees. See the regions searched.
--doubledUses a doubled graph. Uses more RAM than the default method.

The method flags cannot (of course) be combined.

Special cases: parts of a graph with no end

For GFA/GBZ files, the default method needs each connected part of the graph to have an end (a tip, often a chromosome end) or a point whose removal separates that part into several pieces (a cut vertex).

The SPQR framework in Sena et al., 2026 covers parts with neither. The current --spqr-weak-superbubbles option does not yet support this case. The --doubled option can be used, at a higher memory cost.

The --d-bubbles method needs at least two ends and searches regions on walks between them.

Output options

  • -T / --include-trivial includes trivial ultrabubbles.
  • --clsd-trees <file> writes the nesting hierarchy, with the default or --doubled method.
  • --compact-output-chains joins compatible endpoint pairs into chains. See output conventions.

--d-bubbles cannot be combined with --clsd-trees or --compact-output-chains. Common options such as -g, -o and -j are listed in the full command reference.

Snarls

Snarls also allow loops or branches ending inside the region, as in (b). BubbleFinder computes all snarls. The definition was introduced by Paten et al., 2017.

Terminal
BubbleFinder snarls -g graph.gfa -o snarls.txt

The algorithm uses the SPQR-tree framework. See the README for the snarl clique representation.

D-bubbles

We defined d-bubbles using dominator trees. They allow links between nodes inside the region and nodes outside its boundaries, as in (c).

This method needs at least two graph ends (tips). It searches regions on walks between graph tips. The definition and coverage explain which parts of a graph are considered.

Terminal
BubbleFinder d-bubbles -g graph.gfa -o d-bubbles.txt

The preprint describing the definition, proofs and experiments is forthcoming.

Superbubbles

Superbubbles have one entrance, one exit and no internal loops in a directed sequence graph (Onodera et al., 2013).

By default, BubbleFinder reads GFA/GBZ graphs as bidirected. For a directed interpretation of a GFA file:

Terminal
BubbleFinder superbubbles --directed -g graph.gfa -o superbubbles.txt
How a GFA graph is interpreted

Each segment has two states, a+ and a-, representing its two sequence orientations. In bidirected mode, a link L a + b - 0M gives a+ → b- and its reverse-complement arc b+ → a-.

With automatic format detection, superbubbles --directed follows only the direction written in each GFA link record. To read the GFA as bidirected while reporting oriented endpoints, use superbubbles --directed --gfa.

Output and nesting hierarchies

The bubble commands write a text file. Its first line counts the result lines. The remaining lines identify bubbles by their boundary nodes.

snarls, ultrabubbles and d-bubbles report node sides, such as u+ v-. By default, superbubbles reports segment IDs without signs. With --directed, it reports oriented IDs.

Ultrabubbles inside other ultrabubbles

Export their nesting hierarchy with the default or --doubled method:

Terminal
BubbleFinder ultrabubbles -g graph.gfa -o ultrabubbles.txt \
  --clsd-trees hierarchy.txt

Compact chains

For snarls and ultrabubbles, --compact-output-chains joins pairs such as a+ b- and b+ c- into a+ c-. The output contains the two outer boundaries. Snarl clique rows are not compacted.

This option is incompatible with ultrabubbles --d-bubbles. For superbubbles with unsigned endpoints, it leaves the output unchanged. See the complete output format for details.

SPQR trees

SPQR trees split the pangenome graph into smaller parts, making bubbles easier to find (Di Battista and Tamassia, 1990). BubbleFinder builds them with our SPQR-Rust library.

The commands snarls, superbubbles and ultrabubbles --spqr-weak-superbubbles use the unified framework of Sena et al., 2026. Its theoretical running time is linear in the number of graph nodes and links.

Export a decomposition

Terminal
BubbleFinder spqr-tree -g graph.gfa -o graph.spqr

This command reads GFA or GBZ and writes a .spqr v0.4 text file containing connected components, the BC-tree and SPQR trees.
