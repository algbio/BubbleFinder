Documentation / Getting started

Getting started

Build and read an SPQR tree in Rust. For C++, see Choosing a C++ interface.

Installation

Add SPQR-Rust to the dependencies in your project's Cargo.toml:

Cargo.toml
[dependencies]
spqr-rust = { git = "https://github.com/algbio/spqr-rust" }

The repository toolchain file specifies the Rust version used for development.

Input graphs

Graph stores an undirected multigraph. Parallel edges and self-loops are allowed.

Create vertices before adding edges. IDs are consecutive, starting at zero. add_edge returns the new edge's EdgeId.

Graph and SpqrTree use 32-bit IDs. For larger graphs, see Identifier size.

The SPQR builders require a biconnected graph: it stays connected after removing any single vertex. For other graphs, extract the blocks first.

Entry pointInput and result
connected_componentsAny graph. Returns the connected parts and a component ID for each vertex.
BCTree::buildFinds the biconnected blocks and the vertices where blocks meet.
build_spqrA biconnected graph. Returns its SPQR tree, with self-loops collected separately in result.self_loops.
build_spqr_treeA biconnected graph without self-loops. Returns the tree directly.

The following fragment uses an existing graph:

Rust
let components = spqr_rust::connected::connected_components(&graph);
println!("Connected components: {}", components.num_components);

let blocks = spqr_rust::biconnected::BCTree::build(&graph);
for block in 0..blocks.num_blocks() {
    println!("Block {block}: {} vertices, {} edges",
        blocks.block_nodes(block).len(),
        blocks.block_edges(block).len());
}

API source: connected components and biconnected blocks.

Extract biconnected blocks

BCTree::build computes the block-cut tree (BC-tree): the biconnected blocks and their shared cut vertices. Build a graph for each block with vertex IDs from zero and retain the mapping to the full graph. Original vertex and edge IDs in the SPQR tree refer to that block graph. Bridges (edges whose removal disconnects the graph) need no separate SPQR tree.

The complete block example uses two triangles sharing one vertex, plus an isolated vertex. It finds two connected components, two blocks and one cut vertex, then builds and verifies each triangle's SPQR tree.

What an SPQR tree contains

Each SPQR tree node contains a graph called its skeleton, of type S, P or R:

TypeSkeleton
SA cycle.
PTwo vertices joined by parallel edges.
RA triconnected graph: it has at least four vertices and stays connected after removing any two vertices.

A real edge is an edge from the input graph. A virtual edge represents the part connected through another skeleton. Virtual edges come in matching pairs, one in each of the two neighbouring skeletons. They are dashed in the figure.

Build an SPQR tree

This example uses the eight-vertex graph from the overview:

src/main.rs
use spqr_rust::{build_spqr, Graph, NodeId};

fn main() {
    let edges = [
        (0, 1),
        (0, 2), (0, 3), (1, 2), (1, 3), (2, 3),
        (0, 4), (0, 5), (1, 4), (1, 5), (4, 5),
        (0, 6), (6, 7), (7, 1),
    ];
    let mut graph = Graph::with_capacity(8, edges.len());
    graph.add_nodes(8);
    for (u, v) in edges {
        graph.add_edge(NodeId(u), NodeId(v));
    }

    let mut result = build_spqr(&graph);
    result.tree.normalize();
    result.tree.compact();

    let report = spqr_rust::verify::verify_spqr_tree(&graph, &result.tree);
    assert!(report.is_ok());

    let (s, p, r) = result.tree.count_by_type();
    println!("S: {s}, P: {p}, R: {r}");
}

normalize() merges adjacent S nodes and adjacent P nodes to obtain a reduced tree. compact() removes emptied nodes and can renumber the remaining tree nodes. Read IDs after these calls.

Run with cargo run. The output is S: 1, P: 1, R: 2. Download this Rust example.

Read the tree and its skeletons

Skeleton vertex indices are local to each skeleton. The fields below map them to the input graph.

The following Rust fragments use graph and result created in Build an SPQR tree.

Rust
for id in result.tree.iter() {
    let node = result.tree.node(id);
    println!("{id:?}: {:?}, {} vertices, {} edges",
        node.node_type,
        node.skeleton.num_nodes,
        node.skeleton.edges.len());
}
Field or methodMeaning
node.parent, node.childrenConnections to neighbouring tree nodes. The root has no parent: node.parent.is_valid() is false.
node.skeleton.node_to_originalMaps skeleton vertex indices to vertices in the input graph.
edge.real_edgeedge.real_edge.is_valid() is true for a real edge. The value is its input-graph edge ID.
edge.twin_tree_node, edge.twin_edge_idxFor a virtual edge, locate its matching edge in the neighbouring skeleton.

Self-loops are kept in result.self_loops and are not assigned to a skeleton.

Identifiers and tree updates

Canonicalization methods choose a root and order tree and skeleton data consistently. Tree updates can change IDs or move arrays. Retain IDs and create borrowed views (array access without copying) after those updates. See the tree API.

Verify a decomposition

verify_spqr_tree checks edge mappings, skeletons, virtual-edge pairs and tree connectivity. By default it also requires a reduced tree.

To check a tree before reduction:

Rust
use spqr_rust::verify::{verify_spqr_tree_with_options, VerifyOptions};

let report = verify_spqr_tree_with_options(
    &graph, &result.tree,
    VerifyOptions { require_reduced: false });
assert!(report.is_ok(), "{:?}", report.errors);

Failures are available in report.errors. See the verification module.

Export a decomposition

Write the result to a .spqr v0.4 text file:

Rust
let mut file = std::fs::File::create("example.spqr").unwrap();
spqr_rust::spqr_format::write_spqr_format(
    &mut file, &graph, &result).unwrap();

Use to_spqr_string(&graph, &result) for text in memory. Keep the complete SpqrResult to include self-loops. The tree-only functions write_spqr_tree_format and tree_to_spqr_string omit them.

Read and validate .spqr files

parse_spqr_format returns ParsedSpqrFormat records for the file contents. validate_spqr_format checks them against the graph and its SPQR result. Parsing produces file records, rather than a traversable SpqrTree.

Rust
let text = spqr_rust::spqr_format::to_spqr_string(&graph, &result);
let parsed = spqr_rust::spqr_format::parse_spqr_format(&text).unwrap();
spqr_rust::spqr_format::validate_spqr_format(
    &parsed, &graph, &result).unwrap();
