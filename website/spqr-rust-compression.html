Documentation / Compression

Compression

sp_compress shortens paths and merges parallel edges before SPQR construction. This can reduce the work required for graphs containing many such structures.

The remaining graph is the core. Saved records called macros describe the removed structures. Reconstruction uses the macros and the core tree to recover the full SPQR tree.

Workflow

Compression is an alternative to calling build_spqr directly.

  1. Prepare the edge list and mark vertices eligible for path shortening.
  2. Apply series reductions through vertices with two incident edges and merge parallel edges. Store the replacements as macros.
  3. Build the core tree, then reconstruct the full tree when needed.

Reconstruction returns a SpqrTree.

For full-tree output, compare direct construction with the total time for compression, core construction and reconstruction.

Prepare the input

InputMeaning
n_nodesNumber of vertices, numbered consecutively from zero.
InputEdgeThe two vertices joined by an input edge, and that edge's ID. For reconstruction, use each edge's position in the input list as its ID, starting at zero.
contractibleA mask with one byte per vertex. Zero protects the vertex from removal during series reductions. A nonzero value allows its removal when it has two incident edges. Parallel reductions remain possible.

The mask needs at least n_nodes entries. For a full SPQR tree, process one biconnected block at a time.

Check success and error_message in results from compress or compress_borrowed. compress_and_build_spqr instead returns a CompressAndSpqrResult containing macros, an optional core tree and vertex mappings.

Compress and reconstruct

This example uses the graph shown on the project page. It checks the reconstructed decomposition and recovers every original edge.

spqr-compression.rs
use spqr_rust::{EdgeId, Graph, NodeId};
use spqr_rust::sp_compress::{
    compress_and_build_spqr, CompressionInput, InputEdge,
};
use spqr_rust::sp_compress::reconstruct::reconstruct_from_compress_result;

fn main() {
    let pairs = [
        (0, 1),
        (0, 2), (0, 3), (1, 2), (1, 3), (2, 3),
        (0, 4), (0, 5), (1, 4), (1, 5), (4, 5),
        (0, 6), (6, 7), (7, 1),
    ];
    let mut graph = Graph::with_capacity(8, pairs.len());
    graph.add_nodes(8);
    let edges = pairs.iter().map(|&(u, v)| {
        let original_edge_id = graph.add_edge(NodeId(u), NodeId(v));
        InputEdge { u: NodeId(u), v: NodeId(v), original_edge_id }
    }).collect();

    let input = CompressionInput {
        n_nodes: 8,
        edges,
        contractible: vec![1; 8],
    };
    let compressed = compress_and_build_spqr(&input);
    let tree = reconstruct_from_compress_result(&compressed);
    assert!(spqr_rust::verify::verify_spqr_tree(&graph, &tree).is_ok());
    assert_eq!(tree.count_by_type(), (1, 1, 2));

    let stats = compressed.stats();
    println!("Core: {} vertices, {} edges", stats.core_nodes, stats.core_edges_count);
    let mut recovered = Vec::<EdgeId>::new();
    for edge in &compressed.macro_tree.core_edges {
        compressed.macro_tree.for_each_original_edge(
            edge.child, &mut |id| recovered.push(id));
    }
    recovered.sort_by_key(|id| id.0);
    assert_eq!(recovered, (0..pairs.len() as u32).map(EdgeId).collect::<Vec<_>>());
    println!("Recovered {} original edges", recovered.len());
}

Download the complete example. It reports a core with 6 vertices and 11 edges and recovers the 14 original edges. The reconstructed tree has one S node, one P node and two R nodes.

Entry points

FunctionUse
compressCompression only. Takes a reference to a CompressionInput record containing its own edge and mask vectors.
compress_borrowedCompression only. Reads your existing edge and mask arrays without copying them into an input record. Keep them alive for the call.
compress_and_build_spqrCompression plus the core SPQR decomposition.
compress_and_build_spqr_borrowedCompress the graph and build the core's SPQR tree using your existing edge and mask arrays.
reconstruct_from_compress_resultRecover the full tree from a CompressAndSpqrResult, including graphs that reduce completely.
reconstructRecover the full tree by supplying the core tree, macros and vertex mapping separately.
reconstruct_timedReconstruction plus timings for its individual phases.

Read the compression result

The saved macros and core graph form a SpTree, stored in macro_tree. A macro's children are input edges or nested macros. A child reference encodes the child's kind and ID.

ResultMeaning
macro_tree.macrosRecords of the replaced paths and parallel connections. Each gives its endpoints and the positions of its children in the child array.
macro_tree.childrenChild references to original edges or nested macros. Use child_is_edge, child_as_edge, child_is_macro and child_as_macro rather than treating every value as an edge ID.
macro_tree.core_edgesThe reduced graph edges and the child references describing their expansions.
core_spqrThe SPQR result for the core graph. It is None when no separate core tree is needed.
core_node_remap, core_node_invTranslate vertex IDs in both directions: core_node_remap maps original IDs to core IDs and core_node_inv maps core IDs back to original IDs.

SpTree::for_each_original_edge visits the input edges represented by a child reference. count_atomic_descendants counts them for a child reference, and count_atomic_descendants_macro for a macro ID. stats() reports graph sizes and reduction counts.

When fully_sp_reducible is set, the macros represent the entire graph. Reconstruction uses them alone, with core_spqr set to None.

Reconstruction and self-loops

Rust reconstruction returns a SpqrTree. Retain self-loops separately when packaging a SpqrResult for export. C reconstruction results already include them.

Check a reconstructed tree with verify_spqr_tree against the input graph. The comparison module provides canonical_form for byte representations of trees and isomorphic to compare them.

Specialised compression interfaces

64-bit compression is in sp_compress::wide. The C compression interface can read separate endpoint arrays, return timings and expose the core graph. It can also restore an earlier compression state from an in-memory snapshot.

The public adj, arena, pmap and types modules store neighbours, macros and endpoint pairs during compression. See the module index.
